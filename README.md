# 傾き航行プロトタイプ

スマホを傾けて宇宙船を操縦する、宇宙探索ゲームの飛行パートの試作です。ブラウザだけで動きます(3D描画は Three.js)。

## 遊び方

- スマホを横向きにして、傾けて操縦します(パソコンは矢印キー/WASD)
- 右下の「ブースト」を押している間は加速し、燃料を使います(パソコンはスペースキー)
- 押していないと減速し、速度計の赤い線を下回ると近くの星に引き寄せられて着陸します
- 燃料が切れると不時着し、耐久が30減り、着陸後に探索できる回数が1回に減ります
- デブリに当たると減速します
- 着陸すると星の地図が開きます。鉱脈・遺跡・集落・危険地帯などの地点から2か所まで選んで探索し、資源や仲間を手に入れます

## 拠点ステーション

拠点の画面は、宇宙ステーションの中の部屋です。窓の外には今乗っている船が停泊していて、仲間になった人たちが部屋の中を歩き回り、ときどき吹き出しで会話します(派遣に出ている仲間は部屋にいません)。仲間がいないうちは、案内ドローンのピコが話しかけてきます。

- 窓の外の船をタップ → 格納庫、星図のテーブル → 派遣、作業台 → 工房
- 仲間をタップすると一言しゃべる(耐久が低い、派遣が帰ってきた、などの状況でセリフが変わる)
- 素材と仲間の一覧、遊び方は見出しの「倉庫」へ
- 会話のセリフは `js/talk.js` で書き換えられます

## 行商人と買い物

行商人のガランがときどきステーションに来ます。はじめて着陸して戻ったときは必ず来て、そのあとは出撃から戻るたびに40%、または前に来てから6時間たつと来ます。60分(現実の時間)か出撃3回で次の星へ去ります。

- ガランをタップ(または下の「商人」ボタン)で店が開く
- 素材を売るとクレジット(Cr)がもらえる(★1=2、★2=5、★3=12、★4=30、★5=80 Cr)
- 買えるもの:ワープセル(120 Cr)、★2〜★3の素材のまとめ売り、★4の珍品、設計図のかけら(ときどき)
- ワープセルは派遣の画面で使うと、その派遣の残り時間が半分になる(残り10分以下ならすぐ帰還)。遺跡でまれに見つかることもある

## 記録と実績(やりこみ)

今はエンディングのない「やりこみ」型です。拠点の右上の「記録」で、これまでの記録と19個の実績を見られます。実績を達成すると通知が出て、設計図のかけらがもらえます。到達距離の実績(1,000・3,000・6,000・10,000光年)は、今後入れる予定の「謎の信号を追う」物語の節目にそろえてあります。

## 音

効果音とBGMは、音声ファイルを使わずブラウザの中で合成しています。スマホでは最初に画面に触れたときに音が出始めます。音量は「数値の調整」で、オン・オフは拠点の見出しの「音」ボタンで変えられます。

## スマホで遊ぶとき

- 各画面はスマホの横画面に合わせ、上に見出し、真ん中にスクロールする中身、下に操作ボタンを固定しています。ノッチやホームバーにも重ならないようにしています。
- **ホーム画面に追加すると、ブラウザのバーが消えて全画面で遊べます。** iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」です。Android ではホーム画面から開くと横向きに固定されます。
- Android のブラウザで開いた場合は、最初に画面に触れたときに全画面になります。

## スマホで傾き操作を使うには

傾きセンサーは HTTPS で公開したページでしか使えません。GitHub Pages で公開した URL をスマホで開いてください。iPhone では「出撃する」を押したときに、動作と方向へのアクセス許可を求められるので「許可」を選びます。

縦持ちのまま開いた場合は、画面全体が90度回って横画面で表示されます。

## 格納庫(強化・パーツ・造船)

拠点の「格納庫」で、持ち帰った資源を使って機体を強化できます(燃料タンク・エンジン・燃費・姿勢制御・装甲の5種類、各5段階)。強化すると船の3Dモデルの見た目も変わります。

「パーツ」タブでは、技師・装甲職人が仲間になると、それぞれ4種類のパーツを作れます。作ったパーツは船のパーツ枠(小型偵察機は3つ)に付け外しできます。重いパーツほど燃料消費が増えます。

「造船」タブでは、ほかの船の設計図(モデルと性能)を見られます。建造はまだ作っていません。

## 造船と乗り換え

造船士が仲間になると、格納庫の「造船」タブで輸送船(積載90・頑丈)と長距離探査船(燃料が多い)を建造できます。持っている船には「乗り換える」でいつでも乗り換えられます。強化・付けているパーツ・耐久は船ごとに別々です。パーツを別の船に付けると、前の船からは自動で外れます。

## NPC派遣

拠点の「派遣」で、乗っていない船と仲間を送り出せます。現実の時間で進み、ゲームを閉じていても帰ってきます。

- 近く:30分。★1中心の素材を、船の積載量の6〜8割ほど持ち帰る
- 遠く:1時間+自分が到達した距離1000光年ごとに1時間(最大8時間)。遠くまで行ったことがあるほどレアな素材が出て、設計図のかけらも出ることがある
- 採掘士を送ると持ち帰る量1.3倍、航法士を送ると時間が30%短くなる
- 帰ってきたら派遣画面の「受け取る」で受け取る。拠点の派遣ボタンに帰ってきた件数が出る
- 確認用に「数値の調整」の「派遣にかかる時間」を小さくすると早く終わる

## 素材のレア度

素材は星の属性5種類 × レア度5段階(★1〜★5)の25種類です。遠くの光る星や、危険地帯・特殊エリアほどレアな素材が出やすくなります。強化の上の段階には、レアな素材が必要です。

## 積載量

1回の出撃で持ち帰れる素材の数には上限(積載量)があります。小型偵察機は40です。探索中は「積載 27 / 40」のように表示され、超えた分は帰還するときに★の低い素材から置いていきます。積載量は、格納庫の「貨物室」の強化、パーツ「増設コンテナ」、工房の「圧縮バッグ」で増やせます。どれも5つの星の素材を同じ数ずつ使います。

## 工房(探索装備)

道具職人が仲間になると、拠点の「工房」で探索装備を作れます。強化ドリル・精密ドリル(鉱脈での量アップ)、解析ゴーグル(未調査の地点がわかる)と、特殊エリアに入るための装備(防寒スーツ・耐火スーツ・ダイビングスーツ・ハッキングツール・ガスマスク)があります。

## 数値の調整

拠点画面の「数値の調整」から、引力の強さ・減速の速さ・ブーストの加速・燃料量・デブリの量・傾きの感度などを変えられます。値はその端末のブラウザに保存されます。
